## Правила работы

- Работаем по одному нумерованному пункту. Перед началом — две-три строки: что делаешь и какие файлы трогаешь. После: `npm run build` (typecheck + сборка) должен пройти, потом ровно один коммит с названием пункта. Не сваливай пункты в один коммит.
- Стоп в конце каждой фазы, ждём ревью.
- Если прототип и бриф расходятся — бриф главнее. Если прототип неоднозначен — спрашивай, не угадывай.
- Копирайт не выдумывать. Недостающие строки идут в `scripts/strings-to-json.mjs` (`APP_KEYS`) с английским текстом и перечисляются в отчёте по пункту. Хардкод текста в компонентах запрещён, всё через ключи.
- Никаких выдуманных данных. Пустые состояния настоящие. Но заглушек и неработающих кнопок тоже не надо: показываем всё, что можно посчитать честно.
- Библиотеки сверх уже установленных — только с моего разрешения.
- Код, комментарии, коммиты и `DECISIONS.md` — по-английски. Разговор со мной — по-русски.

## Непреложное

1. Только мобильный: цель 390×844, обязан работать на 360×800. Десктоп — то же приложение колонкой 390px по центру на чёрном.
2. Фото крышки не изменяется никогда. Вырезание даёт только альфа-маску; RGB исходных пикселей не трогаем. Оригинал хранится рядом с вырезкой. Разрешено только уменьшение до 1024 по длинной стороне.
3. Детская безопасность: ни настоящих имён, ни чатов, ни геолокации, ни рекламы, ни аналитики кроме логов ошибок. Друзья только по коду-приглашению. Родительский барьер перед удалением аккаунта и функциями друзей.
4. Офлайн прежде всего: добавление крышки работает без сети.
5. Три языка — ru, en, uk, все строки из таблицы.
6. Цвета строго из токенов. Зелёный и красный никогда не единственное отличие состояния — всегда плюс форма, иконка или подпись.

- Строка `reveal.dup` «Another one! ×2» с жёсткой двойкой — нужен ключ с `{n}`.

## Грабли и приёмы

- Windows. Git Bash подменяет значение `BASE_PATH=/probka/` на путь Windows — переменные окружения для сборки задавай через PowerShell.
- Пуш только по HTTPS: SSH-ключ на машине принадлежит другому аккаунту (`yocoge`) и прав на репозиторий не имеет. Токен `gh` для `vrutovich-del` уже с правом `workflow`.
- Каждый пуш в `main` пересобирает и публикует сайт (`.github/workflows/pages.yml`, ~3 минуты). Модель вырезания в git не лежит: локально один раз `npm run cutout-model` (~160 МБ в `public/cutout`, в `.gitignore`).
- Телефон по `http://192.168.x.x` не даёт камеру, сервис-воркер и WebGPU — проверять только на опубликованном сайте.
- Проверять поток удобно синтетическим фото: рисуешь крышку из `uploads` на шумном фоне в canvas, кладёшь `File` в `input[capture]` через `DataTransfer` и диспатчишь `change`. Скриншот сразу после перехода в SPA часто отстаёт на кадр — состояние сверяй через JS и IndexedDB.
- Если панель браузера скрыта, `Image.decode()` в ней не резолвится и скрипт виснет — синтетическое фото собирай через `fetch` → `createImageBitmap` → `OffscreenCanvas`.
- `npm run strings` пересобирает `en.json` из таблицы дизайна; `ru.json` и `uk.json` ведутся руками.
