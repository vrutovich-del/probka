Motion
Reveal — cap drops with bounce 0.6s → settles into −22° pose, slow auto-rotate → +0.3s tier chip pops 0.45s while % counts 0→N over 0.7s → badges slide up 0.45s. Total ≤2.5s.
Duel round — both % count up 0.8s ease-out, then winner/loser chips (✓/✕ + color + border) appear together.
Badge unlock — slide-up + fade 0.45s, stacked with 80ms stagger.
Reduced motion — every sequence above is replaced by a single 200ms crossfade; auto-rotate and inertia are off.
3D viewer — 360° yaw drag with inertia (decay 0.94/frame), tilt clamped ±35°, double-tap resets. Highlight is a fixed light band the texture rotates under. No overlay or filter ever touches the top-face photo.
Rules of the road
Tap targets ≥48px. Body ≥16px, buttons ≥17px. The user's photo is the hero — reference images only appear as small thumbnails in identification. Cutout only: no color correction, sharpening or AI regeneration, dents and scratches stay. Empty states always suggest an action, copy celebrates and never shames. No hard-coded strings in components — every label is a key (strings table).
