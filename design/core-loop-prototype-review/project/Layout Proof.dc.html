Layout proof — Garage in RU / UK
Prototype · Sitemap · Design system · Strings
Russian and Ukrainian run 20–40% longer than English. Same Garage layout at 390px (RU) and the tighter Android width 360px (UK). What absorbs the growth: stat cards wrap their labels, the chip row scrolls horizontally, the segmented control grows by padding, tab labels stay one word, buttons wrap to two lines before truncating. Nothing is hard-coded to a width.
